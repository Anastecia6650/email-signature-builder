Installation Instructions

Gmail

Open Gmail → Settings → See all settings → General → Signature. Create or select your signature, then paste the rendered signature into the editor.

Outlook

Open Outlook settings → Mail → Compose and reply → Email signature. Paste the generated signature into the signature editor.

Apple Mail

Open Mail → Settings → Signatures. Create a signature, then paste the generated signature into the signature area.
