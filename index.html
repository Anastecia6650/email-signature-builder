Installation Guide

Follow the instructions for your email application.

Gmail

  1. Open Gmail on your computer.
  2. Click the Settings gear icon.
  3. Select See all settings.
  4. Stay on the General tab.
  5. Scroll to the Signature section.
  6. Click Create new.
  7. Give the signature a name.
  8. Click inside the signature editor.
  9. Paste the copied signature.
  10. Choose the signature under the settings for new emails and replies if desired.
  11. Scroll down and click Save Changes.
Tip: Use the “Copy Signature” button rather than copying the source code.

Outlook on the Web / New Outlook

  1. Open Outlook.
  2. Open Settings.
  3. Go to Mail → Compose and reply.
  4. Create a new email signature.
  5. Paste the rendered signature into the signature editor.
  6. Choose when Outlook should automatically add the signature.
  7. Save your changes.
Important: Do not paste the raw HTML source into the normal signature editor. Use the rendered signature copied from the Builder.

Classic Outlook for Windows

  1. Open Outlook.
  2. Go to File → Options.
  3. Select Mail.
  4. Click Signatures.
  5. Create a new signature.
  6. Paste the copied signature into the editor.
  7. Select the signature for new messages and/or replies.
  8. Click OK to save.

Apple Mail — macOS

  1. Open the Mail application.
  2. Go to Mail → Settings (or Preferences on older versions).
  3. Select Signatures.
  4. Select the email account.
  5. Click the + button to create a signature.
  6. Paste the rendered signature.
  7. Make sure the signature is assigned to the correct email account.
Tip: If Apple Mail changes the formatting, copy the rendered signature again rather than the HTML source.

Important: Images & Logos

For logos and profile photos to work reliably in email, use an HTTPS image URL that is publicly accessible.

Example:

https://yourdomain.com/assets/logo.png

Do not use local paths such as:

C:\Users\You\logo.png

or:

./images/logo.png

Need Help?

If a signature looks different in an email client, check the following:

  • Images are hosted on HTTPS.
  • The image URL is publicly accessible.
  • You copied the rendered signature instead of the raw source code.
  • Your email client hasn't stripped formatting.
  • Your company email security system isn't blocking external images.
